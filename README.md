# Araw vs Bituin: Tic-Tac-Toe

A two-player Tic-Tac-Toe game built with React and Next.js (App Router), for the SUpost hiring test.

The sun (Araw) and the star (Bituin) come from the Philippine flag.

## Features
- Two players take turns on a 3x3 board
- Shows the winner (with an animated win line) or a draw
- New Game button; the other player starts each new round so it stays fair
- Score board for wins and draws, plus Reset scores
- Works on phones, keyboard friendly, respects reduced motion

## Run it
```
npm install
npm run dev
```

Live: https://araw-bituin-tictactoe.vercel.app
